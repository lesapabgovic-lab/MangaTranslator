Manga Translator Editor Prototype 0.2

Первый рабочий каркас редактора страницы:
1. Открытие JPG/PNG/WEBP через системный выбор Android.
2. Предпросмотр страницы.
3. Поля «Оригинал» и «Перевод».
4. Кнопка OCR-заглушка.
5. Сохранение текста в интерфейсе.

Следующий этап разработки:
- реальный OCR;
- выделение областей текста пальцем;
- удаление/замазывание оригинала;
- автоматическая вёрстка;
- словарь тайтла;
- экспорт CBZ/ZIP.
